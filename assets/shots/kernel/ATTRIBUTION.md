# Kernel Ops screenshot attribution

The three PNG files in this directory were captured from the local Kernel Ops public-demo console and companion site. They are not photographs or mockups of a live customer installation.

Data source for the telemetry and recorded operational views: CARE to Compare, wind farm A — Fraunhofer IEE. Publication: https://doi.org/10.3390/data9120138

The data-derived charts in these screenshots retain the source attribution and are shared under Creative Commons Attribution-ShareAlike 4.0: https://creativecommons.org/licenses/by-sa/4.0/

The project uses the public records as stand-in operational data. Screenshot framing does not establish predictive value, which the application explicitly states is not established.
