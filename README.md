## 🚀 Deploy to GitHub Pages

1. Create a new GitHub repository (e.g. `bala-shunmugam-portfolio` or `<your-username>.github.io`).
2. Upload all files in this folder to the root of the repository.
3. Go to **Settings → Pages**.
4. Under **Source**, select branch `main` and folder `/ (root)`.
5. Click **Save**.
6. After ~1 minute, your site will be live at `https://<username>.github.io/<repo>/`.
